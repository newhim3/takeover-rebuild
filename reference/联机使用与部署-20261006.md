默认原第 7 关中央村庄，2–4 位玩家选择不同国家；默认纯玩家对战，房主可选择加入空缺 AI 国家及 AI 难度，也可选择用户选定的 B「中央高地」大地图。B 使用生成的地图底图与原版单位、建筑、国家地面素材；道路及领地边界仍待实玩校正。条令限额相同，联机条令不写入单人存档。

## 局域网

房主双击 `启动游戏.cmd`。另一台电脑浏览器打开房主局域网地址（联机大厅“邀请地址”），创建/输入同一个六位房间号。另一台电脑不要使用 127.0.0.1，它代表自己。若 Windows 防火墙弹窗，允许该 Node 进程在专用网络通信；本项目不擅自关闭防火墙。局域网监听 0.0.0.0:4387。

## 临时公网

双击 `启动远程联机.cmd`，会启动本地服务及隐藏的 cloudflared 进程，输出一个 HTTPS 临时网址。进入该网址建房，再把网址和房间号给对方；对方也可在本地联机界面填写该服务器地址后输入房间号。房间号不能独自定位任意互联网房主，双方必须在同一入口。

双击 `关闭远程联机.cmd` 会只关闭本项目记录的隧道进程，保留局域网服务。重启隧道网址通常改变。无需 Cloudflare 账号或域名，但临时服务没有长期可用性保证。官方说明临时隧道不支持 SSE，因此已增加 WebSocket，不能用原 SSE 模式直接宣称公网成功。来源：https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/ 。官方 WebSocket 支持：https://developers.cloudflare.com/network/websockets/ 。

程序保存在 `.tools/network/cloudflared.exe`，版本 2026.10.0，SHA256：86aee4017b26625cee8484c113558f48effa4cd47f7aa05fcf425604e5d2b23c；来源 https://github.com/cloudflare/cloudflared/releases/tag/2026.10.0 。下载脚本固定官方版本并校验。

## 正式公网服务器

无第三方 Node 运行库依赖。已有服务器时复制项目运行文件及 assets，安装 Node 24，运行 `node server.cjs`。反向代理必须支持 WebSocket Upgrade，双方从同一个公网域名进入游戏，房间号在这个服务内生效。

提供 Dockerfile，执行 `docker build -t conquest .`，随后 `docker run -d --name conquest --restart unless-stopped -p 4387:4387 conquest`，通过 http://服务器IP:4387 连接。若有指向该服务器的域名，设置 `CONQUEST_DOMAIN=你的域名` 后运行 `docker compose up -d --build`，Caddy 提供 HTTPS 与 WebSocket 代理。compose 配置未实际部署到云主机，本次没有新购云资源。

服务只提供入口脚本/样式和 assets，不公开 tools、reference、.git 或其他本地文件。每个命令仍验证玩家身份与国家归属。房间和对局保存在内存，服务重启会结束对局；不是持久化大厅或全球房间目录。断线八秒按既定规则交给 AI，有客户端重新连接时归还控制；全部玩家离线时暂停模拟以节省资源。
