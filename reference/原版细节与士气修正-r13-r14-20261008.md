# 原版细节与士气修正：r13–r14

本轮保留已认可的页面排版、敌军出兵/集结/回援/目标决策及难度配置。`enemy-ai.js`、`ai-presets.js`、`difficulty.js`、`unit-rules.js`、`spell-runtime.js` 与保存的基线哈希一致。士气攻击增益是独立补上的战斗事件入口，不是 AI 重写，也不改原有攻击倍率和兵种属性。

## 最新反馈的两处修复

**士气现在有可见反馈和完整的网页事件入口。** 成功命中敌方部队增加50士气，无效攻击、攻打城墙、治疗、直接法术和毒持续伤害不会刷这一增益；受击压力、自然恢复和已存在的状态倍率保持不变。原阈值为低于350显示低士气、高于650显示高士气，零士气可进入恐惧，1000可进入英勇；英勇和恐惧持续10秒，结束后回到800/200。纪律只免恐惧；亡灵和机械不参与士气。恐惧不改掉玩家命令，也不新增自动逃跑。

四套原 `MST_*` 动画按原 Flash 注册点叠在徽章上，正常士气不加标记。暂停使用逻辑时间，动画不继续播放。进入英勇/恐惧时分别使用原 `sndUnitHeroic`、`sndUnitFeared`，不会每帧重复播放。悬停部队可看中文士气说明。服务端快照补传当前士气、基值、模式及英雄/恐惧/保护状态，客户端显示服务端结果。

**适配边界：** 原源码逐成员的有效伤害回调会加50；网页战斗按小队合并伤害和士气损失，本轮按一次有效小队命中加50，保持正负事件粒度一致。不是逐兵完整复刻。详细证据见 [士气系统核对](./士气系统核对-r14-20261008.md)。

**胜利星标下文字恢复可读性。** 评级、战斗用时、升星条件、统帅/条令说明和统计数字改成白字深色描边；原王冠、统计条、底纹、经验条和按钮保留，表格和底部位置没有重排。证据见 [一星/三星修前修后对照](./result-readability-r14/说明.md)。

## 加载与定点检查

静态缓存容量从220项增加到768项：菜单和战场资源合计已经超过旧上限，原来的淘汰会让反复进入再次下载。缓存名仍稳定，构建更新不清空原图；联机API和命令不缓存。保留地图及初始可见资源准备后才开始逻辑时间的处理。新的公网域名属于新的浏览器来源，首次打开仍要下载资源。

实际检查范围：

- 一次有效攻击的最小场景先复现“士气没增加”，修后检查增益、无效命中、城堡排除、阈值/持续时间/免疫及服务端字段。
- 静止战场显示四种原士气图标，检查暂停150毫秒后逻辑时间和动画帧不变，无 JavaScript 错误。[截图](./morale-feedback-r14/battle.png)
- 独立一星/三星结算截图，原面板、统计条和文字区域位置不变，白字居中。[三星修后](./result-readability-r14/after-3star.png)
- 离线查看29条选定的单位、建筑和法术时间轴；四国宣告抽帧与本地化源像素比较，未宣称验收每条动画。[动画记录](./animation-check-r13/audit.json)
- 48个运行源脚本语法、111个资源包的1522项原图字节、当前交付哈希及5项 AI/规则基线一致；真实检查资源缓存迁移、240项缓存不再提前淘汰、API绕过缓存。

没有重复跑整套测试、长战役、全关卡模拟或多人实战。上述检查不能证明所有设备帧率、所有战斗场景和关卡胜率都已合适。

## 尚未用上或尚不能完全还原的资料

- 部分 `AST_*` 战斗/动作提示动画还没接到准确的状态切换；可用于驻守、冲锋和远近战提示，需要核对状态与原徽章重叠，不能全部同时堆上去。
- 原攻城溅射 `ExplosionClass` 与地面弹坑有明确来源，但当前溅射反馈还没完整串联；可补原攻城命中细节，不能误用为城堡倒塌。
- 原普通弓箭弹道与网页短线仍有差别；应按原代码形状/颜色复现，不借用别国子弹。
- 近战放射线、部分操作虚线和框选色仍为代码反馈，不能说所有画面已原版。选中反馈是用户明确要求，不能一删了之。
- `DivinePresence` 的邻军士气光环完整触发链未确认，不凭文字猜一个半径和周期。
- 第四国独立原战役数据和部分更新版特效/参数仍缺。当前黑暗战役使用现有关卡适配，本国徽章、条令和法术独立，不等于还原了缺失的整套战役。
- 第7/17/24关边缘遮罩有悬崖修补，部分边缘和国家区域过渡仍需继续对照原对象层；不能把修补遮罩称为原完整地图。B中央高地为用户选择的生成大地图，仍是可选适配，默认第7关不变。
- 补充源码/APK用于对照，不接入运行。原帧导出、方向、重复图和打包副本不算独立内容；本表按用途记录，不能由素材总文件数推导“都用上了”。

AI策略研究与全需求逐项证据另见 [策略资料核对](./策略资料核对-r13-20261007.md)、[需求核对](./需求核对-r13-20261007.md)、[画面素材来源与缺口](./画面素材缺口-r13-20261007.md)。原有混兵、乘虚目标、骚扰、稳定任务、宝箱机会和回援规则保留，资料研究没有被用来重写用户认可的战斗方式。没有新增数值难度奖励；既有高于普通的一次性小额开局资源优势也没有擅自改变。
