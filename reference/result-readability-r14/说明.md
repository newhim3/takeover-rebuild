# 结算文字清晰度修复 · 2026-10-08

结算保持现有原版背景、冠星、统计条、经验条和返回按钮，也保持用户认可的表格排版。本次只改 `native-results.css` 的文字表现，`results-ui.js` 未改。

原样式中，星标下的评级是米黄色，用时和评级提示是灰色；统计条的数字是浅金色，并且只有模糊阴影。原版的金色、绿色、蓝色统计条与亮纹会降低文字对比度。

评级、用时、评级条件、统帅等级/条令说明和统计数字改为白色、加粗并加深色八向描边。经验文字继续保持原有白色和粗体，补齐描边方向。没有加背景卡片、遮色层或改变任何图片。

## 实际检查范围

用隔离的浏览器和独立的静态结算页面，渲染绿色国家的一星和三星胜利固定示例。页面只加载原结算素材和样式，不加载游戏运行脚本，不读取/修改玩家存档，不运行战役，不连接正式联机服务。

- 一星与三星的修前/修后截图各一张；所有原素材图片完成加载，未出现 JavaScript 错误。
- 比较原面板、底部区域、统计行、统计条及文字所在区域的实际位置，保持不变。数字加粗后字面宽度略增，但仍处于原统计条中心。
- 此检查只覆盖这两个结算固定画面，不代表所有分辨率、所有游戏流程或战役平衡已经实玩验证。
