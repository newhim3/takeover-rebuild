# 本轮修改（r10）

范围按用户“改吧，敌人 AI 的逻辑不要改”执行。补充的第三方游戏源码仅用于对照，没有接入、执行或加入网页公开目录。原 UI、结算排版、地图道路和各国数值没有重设计。

## 已写入

- 动作图片通过 `animation-cache.js` 限制同时下载/解码数量，提前准备场上兵种及己方可招募兵种的四向行走、攻击与当前建筑动画；当前素材保留，旧素材按估算的解码内存预算回收。96 MiB 是缓存估算预算，正在使用的素材可以超过此预算，不代表实际 GPU 内存上限。
- 原地图生成器把 `mcArea`、道路与 `mcObjects` 分开。地面继续按归属缓存，原坐标、原国家帧的树木和山石用小位图复用，按图形脚底与单个士兵共同排序。导出窗口外、脚底完全没有原地面支持的装饰不在全岛镜头中显示；没有补画地形或自造桥。
- 联机增加完整基准包和变化包。变化包均参照最近完整包，不依赖上一条变化包；兵种定义、路径等未变化字段不重复发送。加入、重连、周期同步与缺失基准时恢复完整状态；新基准同时发送给已连接玩家。血量、经济和归属继续只由服务端计算。
- 手动新命令和停止命令增加版本号，尚未命中的旧攻击在命令已变化时失效；保留已有接敌、撤离和原目的地规则。没有重写敌人下令策略或完整战斗状态机。
- 单机和服务端采用同一 0.05 秒逻辑步长，累计实际经过时间并限制长卡顿后的补算。单机显示插值只作用于位置、朝向与行走距离，不插值血量；暂停仍冻结时间。
