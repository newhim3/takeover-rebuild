# 同网联机使用与优化

日期：2026-10-09。

## 不填网址的玩法

1. 两台或多台 Windows 电脑使用同一版完整游戏目录，连接同一可互通的家庭局域网。可通过 Wi-Fi 或网线连接同一路由器。
2. 各自双击目录中的 `局域网联机.exe`，自动启动本机服务并打开联机大厅。它默认进入联机，无需命令行参数；原 `城邦征战.exe` 默认进入首页。CMD 入口作为备用保留。
3. 房主点击“创建房间”。朋友等几秒，在“同网房间”点击对应房主的“加入房间”；也可以直接输入六位房间号，程序会寻找它所属的同网主机。
4. 各自选择不同国家、分配条令并准备。房主开始对局，控制速度与暂停。默认纯玩家对战，可开启空缺国家 AI；原第 7 关仍是默认地图，B 中央高地仍可选择。

朋友不需要复制或填写房主网址。加入同网房间后，地图、原 UI、动画和音频继续从自己的本地目录加载，只有大厅操作、指令和权威战场状态往返房主电脑。双击 exe 并不要求切换到 Unity，也没有重写现有游戏核心。

## 首次连接与找不到房间

首次 Windows 询问是否允许游戏服务联网时，允许可信家庭网络的专用网络访问。若房间始终无法发现，可以右键 `启用局域网联机防火墙.cmd`，选择“以管理员身份运行”。脚本仅给游戏目录内的 Node 程序设置专用/域网络、同一子网、TCP 4387 与 UDP 44987 的入站规则。`移除局域网联机防火墙.cmd` 可以撤销。移动目录后需重新设置对应程序路径。

本轮只交付了脚本，没有擅自修改系统防火墙或网络类别。脚本的范围参考 [Microsoft 防火墙命令说明](https://learn.microsoft.com/en-us/powershell/module/netsecurity/new-netfirewallrule)。

访客 Wi-Fi、路由器“客户端隔离”、不同 VLAN 或禁止广播的网络可能让设备不能互相发现或连接；仅显示相同 Wi-Fi 名称并不能解除这些网络限制。当前自动发现用于可互通的 IPv4 局域网，不宣称实现了跨网络公网穿透。远程邀请、临时公网入口和手动服务器地址保留在折叠入口中。

两个目录的构建版本不同会提示“游戏版本不同”并禁止同网加入，避免客户端原单位表或素材索引与房主计算不一致。启动器同时核对本目录与本地服务的构建号；发现旧版本时，只会重新启动能够核验为本目录托管的服务。也可双击 `重启本地联机服务.cmd`。未知进程或其它目录的程序不会被关闭，需先关闭原目录中的游戏服务。服务重启会结束旧房间，需要重新创建。

## 本轮体验优化

- 通过真正的往返延迟判断连接。房间所有有效连接延迟不超过 80 ms，且无传输积压时，快照发送间隔由 100 ms 缩短到 50 ms；未知、远程或拥堵连接继续使用 100 ms。
- 稳定低延迟连接的显示缓冲随快照间隔降到约 52.5 ms，最低 50 ms；远程和未知连接保留至少 110 ms，并随网络抖动增加。这个数字是缓冲规则及定点输入的结果，不是对任意电脑的实际点击延迟保证。
- 行军继续使用有限的本地视觉反馈；血量、经济、归属、法术与战斗不在客户端重新计算。血量和归属仍取同一个离散权威状态，显示时间不回退，位置才平滑过渡。
- 新移动指令或反向路径到达时，停止沿旧方向外推；部队死亡或被转化后，清掉原玩家的待确认行军预览，避免继续覆盖新归属的路径。
- 房间列表短暂断网后能够恢复；退出再进入联机菜单时，旧请求不会覆盖新列表或关掉新的刷新任务。
- TCP 连接收到对方关闭后立即清理 WebSocket，及时确认断线，不再等 15 秒心跳。原断线八秒 AI 接管与恢复后归还控制的规则保留。
- 本地中继复用连接、采用流式转发，关闭时清理 UDP、代理和长连接。公开发现信息没有玩家身份密钥、条令、金币或战场快照；公开网址访问者不能枚举本机邻居或借用中继。

发送、插值与响应延迟的取舍参考 [Valve 联机说明](https://developer.valvesoftware.com/wiki/Source_Multiplayer_Networking)。本轮保留原模拟时间步、敌军决策时钟、全部 AI 策略、兵种倍率、法术和战役配置。

## 实际检查边界

本轮仅做与新增功能和已找到根因对应的检查：同机两个 UDP 实例真实发现、HTTP 房间请求及 WebSocket 双向中继、连接关闭、版本不匹配拦截、启动器与服务生命周期、客户端加入/重连来源、缓冲与血量离散帧。另启动了同机两个独立服务进程，用真实中继与 WebSocket 确认暂停招兵、重复指令去重、恢复行军及断线归还身份后的金币、生命、部队与归属一致；检查中的逻辑时间保持为零，未推进战役。C# 启动器已重新编译，脚本语法已检查。

记录见 `.tools/r25-lan-check.json`、`.tools/r25-lan-lifecycle-check.json`、`.tools/r25-lan-version-check.json`、`.tools/r25-client-route-check.json`、`.tools/r25-transport-check.json`、`.tools/r25-websocket-close-check.json`、`.tools/r25-authoritative-lan-check.json`、`.tools/r25-client-followup-check.json`、`.tools/r25-motion-order-check.json` 和 `.tools/r25-launcher-policy-check.json`。没有反复运行旧整套测试、长战役模拟或浏览器游玩，也没有在两台实体电脑上完成整局验证；实际手感与网络环境由用户反馈。
