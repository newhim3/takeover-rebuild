# 兵种能力和正常难度条令映射

本次保留原始 45 条单位记录及先前指定的弓箭手 0.85 射程，不靠临时加伤害改善雪国表现。

- `progression.js` 的普通招募筛掉零价格、零补给、食人魔和 Avatar。Avatar 的原记录仍然可通过 `special('Avatar')` / `UNITS.find` 获取，绿色终极法术先播放原大招声明，再召唤 `GreenMagic3`，不进入魔法塔普通招募队列。
- `equivalentBonuses(sourceColor, targetColor, levels)` 接收条令等级，按“基础、旗帜、进攻法术、各兵种、终极条令”映射目标国家自己的法术和专属条令。五类兵种升级和通用数值直接与玩家对应；不会让雪国带上黑暗帝国的转化概率或亡灵伤害加成。
- `UnitRules.tickCombatPassives` 和 `applyHitEffects` 分别负责每帧被动、命中后的状态。父引擎需要调用两者，不能保留旧的毒和巨型机械回血分支同时叠加。
- 巨型机械回血按小队所属国家的 `bonus[40]` 生效，不再只针对玩家，也不把任意三阶弓手当成巨型机械。
- 毒只属于原本带 `Poisonous` 的单位。条令 24 加在这项能力上；不会使全部红国士兵都变成毒兵。原效果每名存活成员分别损血，持续 3000ms，首次脉冲后每 3 秒脉冲，不是整队每秒损 2 点血。亡灵、机械和毒免疫单位抵抗毒。重复命中刷新持续时间而不重复叠加即时脉冲。
- 冻结箭、冻结爆分别降低移动和攻击速度 50%、40%，持续 `3 + 条令30` 秒。步兵条令33则按概率触发完全冻结。同一命中不凭空增加额外冻结伤害。
- 冰霜附魔原本令攻击按最大伤害取值并抵抗伤害/冻/毒。已为毒脉冲、兵种冻结及冰霜冲击接入附魔抵抗；原先直接写入完全冻结会绕过这项抵抗。

本地原始源码位于 `../takeover拆解/extracted/swf2/scripts_clean/scripts/`：

- `battle/§_-DM§.as`：原始单位记录。
- `§implements§/§_-vg§.as`：207–209 行毒条令仅附在 Poisonous；461–474 行毒的 3 秒脉冲/3000ms 持续、冻结箭/爆的百分比及概率冻；97–101 行冻结同步作用于 SPEED / ATTACK_SPEED。
- `§implements§/§_-kQ§.as`：首次触发和周期脉冲；`§_-UC§.as` 将毫秒持续时间除以 1000。
- `§implements§/§_-qT§.as`：寒冰附魔抵抗物理、冲锋、毒和冻结效果。
- `§_-qG§/§_-eB§.as`：242–282 行只有 SplashDamage 参数大于 0 才发出范围命中。Wizards 原记录无 SplashDamage，暂不根据“FreezeBlast”名字编造额外跨小队爆炸半径。
- `level/Level.as`：冰霜冲击先播放投射素材，完成后施加状态；寒冰附魔调用每成员的保护和最大伤害效果。
