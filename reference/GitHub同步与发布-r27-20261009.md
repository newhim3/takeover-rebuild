用户已授权后续更新继续同步：完成修改与必要检查后提交并推送；更新单文件 EXE 时发布对应版本的 Release 附件，并核对远端提交及附件状态。本次版本为 r27 / v0.27.0，游戏构建仍为 `4d5bf4f92ed803c8`。

本次完善发布过程：

- 发行范围以 `config/runtime-assets.json` 版本管理，保留 5,112 个资源，与 r26 一致。
- `tools/build-release.ps1` 重建交付文件和三个启动器、校验资源、生成 ZIP 与单文件 EXE。
