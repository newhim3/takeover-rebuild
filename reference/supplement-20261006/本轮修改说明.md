# 操作与画面优化，2026-10-06 r9

本轮遵循最新要求：补充源码不接入游戏运行，只处理调遣、渲染和地图显示。原版界面、结算排版、兵种数值、AI 策略与资源制度不在本轮重做。

## 调遣与流畅性

- 多部队短距离移动的队形间距被限制在路程的 30% 和 80 个世界单位以内。旧实现按部队数量无限累计间距，后排的目的地可能倒退至起点。
- 手动改令去宝箱、地面或友军城堡时保留新目的地。与敌军接触时仍反击，但不因自动追击重新延伸旧任务；可以边打边退，敌军正面堵路时必须交战。
- 修正狭窄道路上的友军排队互相等待。等待超过 0.45 秒后允许低速压缩友军间距，敌军阻挡规则仍生效。
- 行军避让及附近敌人检索改为每个模拟步共用空间索引，减少每支部队反复遍历全部部队。索引保留移动余量，并在部队数组或数量改变时重建。按部队 ID 的检索也复用索引；没有目标时直接返回，避免空闲部队互相遍历。
- 联机移动预览也检查前方敌军接触，减少等待确认时穿过敌军再被服务器拉回的视觉跳动。预览不计算伤害或经济。

## 原地图显示

- 原地图遮罩、滤镜和国家地形帧只在地图或归属改变时生成。镜头缩放、拖动及窗口分辨率改变复用世界地图位图，不再次运行原地图绘制脚本。
- 保留最多两份地形缓存，避免无限保留历史地图或归属组合。
- 采用已有地图 PNG 的透明边界和 SWF 坐标，包含可行走区外的山体、悬崖。固定取景边界，避免占领后镜头突然缩放或偏移。
- 战役也支持滚轮缩放和中键拖动；鼠标坐标、建筑操作面板和部队选中继续使用同一镜头变换。
- 不替换原地形、不添加颜色罩，不新画 UI 或桥梁。原素材本身的地形轮廓仍保留。
