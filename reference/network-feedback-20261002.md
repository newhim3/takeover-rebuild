# 联机及界面反馈修正 · 2026-10-02

本轮规则替代此前的四图拼接配置，大地图暂不制作。

## 地图和领地

采用原第 7 关：中央村庄、六处据点、三个食人魔和三个宝箱，800 × 600，非最终关卡。原地形、原道路、原据点与建筑位坐标保留，不造桥。两人开局在左上/右下原城堡，另外两国由 AI 控制；四位玩家也支持。原右上塔在联机配置中改为第四国大城堡，中央村庄和另一座塔由 AI 国家正常拥有，所有据点开局完整，不是废墟。

领地绘制与单人关卡共用 `NativeMaps[7].draw(canvas, ownerFrames)`，据点归属、修复归属改变会刷新对应国家的原地形帧，包括原装饰和环境，不叠颜色滤镜。

## 手感与调速

- 部队固定资料通过 ID 缓存，生成、升级、转化或恢复连接时发送；普通同步只发显示和指挥需要的状态，不再反复塞入整条兵种表。
- 同步间隔由 120 毫秒改为 50 毫秒；浏览器在两次同步之间平滑显示位置、行走与攻击动画、特效，不自行决定伤害和归属。
- 玩家移动指令立即显示命令与路径，服务器确认后接回正式状态；拒绝指令会清除预测。
- 未登场兵种的全部朝向、死亡动画和未使用法术不再一次性预载，当前部队按需加载，上一场动画缓存释放。
- 原道路最短路径缓存，不在每次寻路时重新遍历整图。菜单覆盖时停止绘制被遮住的战场；画布像素比例上限由 3 调至 2。
- 房主用速度按钮切换 1/2/3 倍速、暂停按钮暂停或恢复，全员由同一服务器流速运行。其他玩家只能查看流速。

这些修改针对已确认的卡顿来源，尚不承诺所有设备达到固定帧率。

## 钱款

检查了全部普通战役的开局：300 基础金币加对应条令收益；预先招募的部队均扣费；没有预建免费矿场、农庄或方尖碑。敌人可在前十秒付费发展但不主动进攻，防守允许。

普通联机 AI 的条令实际投入跟随玩家实际已投入点数，不自动用满房间限额；其他难度仍在房间同一限额内配置。购买、建筑、升级实际扣款。原地图的国别据点数量不同属于地图配置，没有额外增发开局资金。

## 界面

保留用户认可的清晰结算表格。统计条恢复原 2321 的四国背景与边框，徽章独立导出，避免重复旗帜和错删不同国家的底板；顶部用原 2236 横框。保留原未染色黑布背景，不扩成满屏国家色。

关卡皇冠重新裁出原图实际图形显示范围，居中对齐城堡顶部；修正黑暗城堡图标比例。等级与经验采用粗白字和深色描边，经验数值仍在原进度字段，字体显眼。选择战役、条令和条令重置等已有原按钮框只覆盖文字，不额外叠第二个框，新增难度按钮复用同一原按钮。

## 检查范围

一次针对性联机检查覆盖两人/四人、原地图、完整四国据点、房主调速与暂停、指挥和扣款权限、驻军迎击与争夺废墟。另核对普通战役构造时的开局钱款及建筑位。界面使用独立静态示例对照原图，不改玩家存档，不运行整套战役游玩。实际手感继续由用户反馈。

临时双人浏览器房间已核对首次同步、正常扣款招募、2 倍速、暂停和对应国别原地形，客户端未记录同步错误。房间已退出；没有写入战役存档。黑暗城堡原 PNG 在关卡 UI 内的缩放按原地图图标尺寸适配，其皇冠采用对应的顶部位置。
