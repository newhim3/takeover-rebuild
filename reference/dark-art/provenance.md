# 黑暗帝国入口插图来源

更新日期：2026-10-01。

入口中央图案采用解包的原作亡灵帝国徽章，原始 SWF `GameIntroClass`（角色 6389）的第 181 帧开始放置角色 6282。图案包含破损的银灰王冠、紫色宝石与骷髅，在开场里表示已经落入亡灵法师手中的里瓦迪斯帝国。原始静态矢量已导出到 `vector/DefineSprite_6282/1.svg`，应用文件为 `assets/takeover/ui/empire-crest.svg`。

旗帜格式沿用原战役入口的空白布面轮廓和缝边（原角色 6651、6657）。提取时完全移除了原入口的裁切人物和国家徽章组，只让空布面适配帝国徽章的灰紫色。应用入口 `assets/takeover/ui/native-campaign-flag-Purple.svg` 不包含赤焰部落的人物、图腾或颜色滤镜。

发布方 [ArmorGames 原作发布介绍](https://armorgames.com/news/new-release-the-takeover)说明帝国被亡灵法师控制，以及原作提供三个可选国家。这与本地开场图案及战役界面结构相符。本地原作没有第四个玩家战役入口，也未找到独立的帝国统治者人物立绘，所以本入口采用真实的帝国徽章，而没有用其他国家人物冒充。

生成脚本为 `tools/restore-empire-campaign.py`，常规 UI 恢复脚本 `tools/restore-unit-ui.py` 也会调用它，防止以后重新生成时恢复到红国改色的旧方案。三个原生入口和帝国入口的 SVG viewBox 均为 `-150 -245 300 490`。

战役选择页允许内部旗帜以 1.04 倍柔和扩大，入口位置、点击范围不变；国家介绍在布面下部淡入。这个效果只作用于国家选择入口，不作用于游戏里的招兵、法术及其他按钮。
