# r8：暂停即时购买、保留资源据点、有限追击与本地启动

按本轮最后的明确反馈，占领附属建筑采用**保留**规则，覆盖此前“清空后立即重建”的回答。没有增加新 UI 卡片或修改已认可页面布局。

## 暂停

招兵、建造、升级、拆除立即检查费用、人口和权限，扣款或退款并显示结果。士兵保持在城堡内，建筑显示当前状态。暂停期间模拟时间不推进，移动、战斗、资源生产、修复、回血、熟练度和动画保持静止。

移动、停止和施法可以预先下达，恢复后按顺序执行。联机中服务器同样只暂存这三类命令；购买立即发送权威快照。重复指令编号不会重复扣款，暂停后购买仍受余额和人口限制。房主控制流速，其他玩家仍能提交购买和预先调遣。

## 领地与追击

原有金矿、农庄、方尖碑及购买成本保留。首次入驻确立归属时，附属建筑及其收益转归新主人，空位可以立即建设、已建建筑可拆除。据点自身的招兵、人口和终极塔蓄能仍需修复完成。无人占领的废墟不产生附属建筑收益，旧主人不能在其上建造。

部队接敌后记住交战起点。步兵追击约 125 世界单位、骑兵 180、远程 110，离开攻击范围累计追赶不超过 7 秒。越界后指定追击返回交战起点，行军途中接敌则恢复原目的地，并暂时抑制对同一逃敌的远距离再追踪。玩家重新明确下令会覆盖此限制。时间限制不打断原地持续交战，也不妨碍首次走向远处指定目标。食人魔保留独立领地范围。

黑暗终极法术转化场上非机械、非驻城敌方小队的一半，奇数向下取整。原始法术表及视频来源表保留；该行为是用户指定平衡，显示说明覆盖原“最多三队”，不声称固定原表已证明百分比规则。

## 难度与目标判断

普通仍为 300 金币、70 法力（再加本国已点条令）。困难/精锐/噩梦 AI 一次性多 15/30/45 金和 5/10/15 法力；人类国家不享受 AI 额外储备。不存在额外收入倍率、免费兵或领先科技。

目标评分增加附属金矿、人口和法力设施价值，以及缺少魔法塔时的战略价值。高难度预测附近守方援军是否能在攻城结束前到场：每目标最多考察六队、最多十八秒范围，难度逐级增加预测权重；评分只在 AI 决策时执行，仍保留随机偏好和任务稳定性。AI 新占领地也可以在修复中建设附属建筑。

设计参考 [GDC《Improving AI Decision Modeling Through Utility Theory》](https://media.gdcvault.com/gdc10/slides/MarkDill_ImprovingAIUtilityTheory.pdf) 的风险、收益与距离共同评分思路。当前是启发式决策，**没有训练机器学习模型，也没有证明其能胜过人类高手**。

## 加载与 EXE

菜单覆盖战场时停止隐藏战场 UI 的定时刷新。四国底栏及三类招募面板的左右原素材加入静态缓存，总计从 185 增至 212 项；这 27 个新增缓存全部由现有 SVG 栅格化，保留原位置及透明范围，没有生成新 UI。原 SVG 保留，战场调用映射后的 WebP，缺失映射则使用原图。完整清单见 `native-menu-cache-audit.json`。

根目录 `城邦征战.exe` 是 Windows 本地启动器，源码为 `tools/local-launcher.cs`，使用随目录保留的 `.tools/native/node.exe` 启动现有服务，并以 Edge 独立应用窗口打开。已有服务时复用，不关闭正在进行的房间。关闭窗口后服务仍可供局域网玩家连接。启动器必须与完整项目目录放在一起，不能只发一个 EXE。

本地单人和本机/局域网服务从本地读取素材，避免公网素材下载等待。它仍使用原 Canvas/JavaScript 核心，不是 Unity 移植。远程地址加入目前仍跳转到该服务器页面，远程网络时延不会仅凭这个启动器解决。浏览器存档按页面来源和浏览器配置保存，不自动迁移 Codex 内置浏览器存档。

## 定点检查与限制

`tools/occupation-pause-chase-check.cjs` 覆盖半数转换、修复中保留建筑与建造、单人暂停立即购买、联机暂停扣款/去重/快照/恢复命令、无人占废墟权限、普通/高难度资源、人类不享 AI 储备、有限追击及手动覆盖、资源中心选择和增援预测。已通过十项。

EXE 已编译，`--check` 不打开窗口，确认文件就绪并能访问本地服务。缓存文件及 JavaScript 做必要语法和依赖检查。没有重复跑完整战役、浏览器游玩或公网双人实战，也没有 FPS、加载耗时的现场测量；画面和对战体验等待用户反馈。
