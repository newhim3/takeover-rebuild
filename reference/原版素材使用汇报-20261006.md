# 原版素材使用汇报（2026-10-06）

以当前 `assets/takeover` 为范围，共 12,152 个文件，约 511.14 MiB。不是 12,152 种独立画面：其中包含原 SVG 源帧、动画图集、方向、血量/进度状态、旧裁切和重复导出。

完整逐文件清单见 [素材使用清单-20261006.csv](素材使用清单-20261006.csv)，包含路径、大小、接入证据或未使用原因、可能用途；统计见 [asset-usage-20261006.json](asset-usage-20261006.json)。工具为 `tools/audit-asset-usage.cjs`。

统计口径是静态代码引用及明确的渲染分派，不是游玩录屏覆盖。代码接入表示相应国家、关卡或状态可以选用，不保证本次每一个状态都已实际显示。原始源档没有被浏览器逐帧直接读取，视觉通常来自它们生成的 PNG 图集或拆分 SVG。

## 未用上的内容、原因和可能用途

| 未用素材 | 原因 | 可能用途 / 下一步 |
|---|---|---|
| 大量原 SVG 逐帧源档 | 已整理为图集/独立 SVG，直接加载整套会增加文件请求和解析量 | 保留核对、修复注册点、重新导出精确层次。保留源档不等于没复用其中原画 |
| LevelNClass 单张全图 PNG | 烘焙默认阵营，不能随领地归属切换；部分有导出编辑框 | 本次用25张全图作生图参考；正式地图继续使用地区时间轴 |
| GraphMarkers / HitMask | 编辑与碰撞用途，不是正式可见图形 | 原道路、建筑坐标与通行核对，不显示在地图上 |
| 左/右/上方向 Die | 当前死亡只播放 Down，方向完整性仍有缺口 | 后续保留死亡朝向并接入对应原帧，不能说四方向死亡已经完成 |
| SpecialA–E 专用动画 | 各自原状态、触发和帧时点尚未逐项落实 | 冲锋、特殊攻击、召唤或能力状态；先对照原类和视频再映射 |
| Bullet / AcolytesBullet / GunbotBullet / GiantbotBullet / ZealotBullet | 普通命中弹道目前仍含简化线段，未按武器全部接入原弹体 | 法师、火枪、机械等弹道；命中与飞行应分开，属于仍需完善的真实表现 |
| 成就页/弹窗、原存档页、帮助/暂停完整动画 | 对应原流程不完整，部分页面只拆用了原按钮和底图 | 成就、存档、帮助系统完整复原；整页硬叠会遮挡现有中文交互 |
| 中间统计条帧 | 使用原首帧/满帧并裁切表现进度，未加载所有同形变化帧 | 可恢复原逐帧增长，但应评估重复请求；经验条和血量条按状态选择帧 |
| 部分旧面板、圈选图、patched 素材 | 被更正确的原 HUD、徽章或招募框替换；不能覆盖用户认可界面 | 历史回溯和对照，不主动重新启用 |
| 更多原音频 | 尚未按武器/种族、建造、状态、升级等事件全部对应；匿名 snd 编号更不能猜 | 扩充原声反馈，先对照 `media/SoundConst.as` 和触发类 |
| 匿名 # 编号、未追踪位图 | 尚未确认类名或用途，静态审计未发现引用 | 用 symbols.csv、源类和帧导出辨认；报告明确列为待确认，不假装还原完成 |

本次新生的大地图候选不属于原版素材。它们参考原地图布局和四国地形画风生成，待玩家挑选后才能制作碰撞、建筑坐标与四国地区替换帧。没有替换当前第7关地图，没有把 AI 生图当作原素材。
